# Earth Textures

This directory should contain the following texture files for the Earth visualization:

## Required Textures:

1. **earth_daymap.jpg** - Earth day texture (Blue Marble)
   - Download from: https://visibleearth.nasa.gov/images/57752/blue-marble-land-surface-shallow-water-and-shaded-topography
   - Resolution: 2048x1024 or higher

2. **earth_normal_map.jpg** - Earth normal map for surface detail
   - Download from: https://visibleearth.nasa.gov/images/73934/topography
   - Resolution: 2048x1024 or higher

3. **earth_specular_map.jpg** - Earth specular map for water reflection
   - Download from: https://visibleearth.nasa.gov/images/57747/blue-marble-bathymetry
   - Resolution: 2048x1024 or higher

4. **earth_clouds.jpg** - Earth cloud texture
   - Download from: https://visibleearth.nasa.gov/images/57747/blue-marble-clouds
   - Resolution: 2048x1024 or higher

5. **milky_way.jpg** - Milky Way background texture (Optional)
   - Download from: https://svs.gsfc.nasa.gov/3895 or ESA Gaia mission images
   - Resolution: 2048x1024 or higher
   - Alternative: The app will generate a procedural Milky Way if not found

## Alternative Sources:

- NASA Visible Earth: https://visibleearth.nasa.gov/
- Natural Earth: https://www.naturalearthdata.com/
- Blue Marble Next Generation: https://visibleearth.nasa.gov/collection/1484/blue-marble

## Notes:

- All textures should be in equirectangular projection
- Higher resolution textures will provide better visual quality
- Ensure textures are properly licensed for your use case
- The application will work with placeholder textures if these are not available
